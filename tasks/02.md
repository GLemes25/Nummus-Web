Objetivo: Aplicar padronização rigorosa de idioma e Clean Code em todo o frontend (Nummus Web).

Contexto: Precisamos refatorar os arquivos do projeto para garantir uma separação clara entre a linguagem da máquina (Inglês) e a linguagem do usuário (Português do Brasil), além de eliminar ruídos visuais no código.

Tarefas de Refatoração (Aplique em todos os componentes e páginas):

Código Estritamente em Inglês: Renomeie todas as variáveis, funções, hooks, interfaces, tipos, parâmetros, nomes de arquivos e pastas para o Inglês. Exemplo: dadosUsuario vira userData, lidarComClique vira handleClick.

Zero Comentários: Remova absolutamente todos os comentários do código (// ou /\* \*/). O código deve ser autoexplicativo através de bons nomes de variáveis e funções. As únicas exceções permitidas são diretivas essenciais do sistema, como 'use client'; ou comentários de supressão do ESLint/TypeScript (ex: // eslint-disable-next-line).

Interface de Usuário em pt-BR: Todo texto que for renderizado na tela para o usuário final deve estar em Português do Brasil. Isso inclui labels de botões, placeholders de inputs, mensagens de erro, toasts, descrições e propriedades aria-label para acessibilidade.

Manutenção das Regras de Projeto (Verifique se não foram perdidas durante a refatoração):

Regra de UI (Transparência): Certifique-se de que nenhum modal, slide-over ou janela em foco perdeu a sua classe de transparência. Eles devem manter rigorosamente 90% de opacidade (ex: bg-zinc-950/90).

Regra de Versionamento: Ao concluir essa refatoração estrutural, gere o commit. Lembre-se que a mensagem desse commit deve ser escrita obrigatoriamente em Inglês.
