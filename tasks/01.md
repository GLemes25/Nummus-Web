**Objetivo:** Refatorar e adaptar componentes React brutos exportados do Figma para o padrão Next.js (App Router) com Tailwind CSS e shadcn/ui.
**Contexto:** Acabei de colar os componentes gerados pelo Figma no projeto `nummus-web`. Eles possuem estrutura visual correta, mas a arquitetura e as importações não são adequadas para o Next.js moderno.

Utilize como regras padroes o .claude/rules

**Tarefas Críticas de Refatoração:**

1.  **Diretivas de Renderização:** Analise os componentes. Adicione `'use client';` no topo de qualquer arquivo que utilize hooks (`useState`, `useEffect`), manipulação de eventos (`onClick`) ou componentes do Radix/shadcn que dependam do lado do cliente.
2.  **Roteamento e Otimização:** Substitua todas as tags `<a` genéricas por `<Link` do `next/link`. Substitua tags `<img` por `<Image` do `next/image` (configurando width/height ou fill apropriadamente).
3.  **Integração com shadcn/ui:** - O Figma provavelmente importou primitivas direto do `@radix-ui/react-*` ou do `@mui/material`.

- Para animações, siga uma abordagem em duas camadas: use estritamente as classes do tailwindcss-animate (como animate-in fade-in zoom-in) para transições simples de estado (hovers, exibição de elementos menores). Reserve a biblioteca motion exclusivamente para animações de layout complexas, gestos (drag) e para a entrada suave do Modal de 90% de opacidade.
- Substitua essas importações pelos componentes corretos do shadcn/ui localizados em `@/components/ui/`.
- Se o componente do shadcn/ui necessário não existir no projeto, utilize o comando `npx shadcn@latest add [nome-do-componente]` para instalá-lo antes de continuar a refatoração.

4.  **Limpeza de Classes e Tailwind:** Remova estilos inline (`style={{...}}`) e cores hardcoded (ex: `bg-[#7C3AED]`), substituindo pelas variáveis do Tailwind configuradas no projeto.

**Regras de UI e Padronização (Atenção redobrada):**

- **Comportamento de Transparência:** Modifique o código de todos os modais, pop-ups, dialogs, janelas focadas e slide-overs. Eles devem manter estritamente **90% de opacidade** quando em foco, utilizando classes como `bg-zinc-950/90 backdrop-blur-md`. Sob nenhuma hipótese esses elementos devem perder a transparência inteiramente.
- **Controle de Versionamento:** Ao finalizar a refatoração e realizar o commit, a mensagem do commit gerada deve ser obrigatoriamente escrita em **Inglês**.
- **Documentação:** Se for necessário atualizar o `README.md` ou criar arquivos de regras de contribuição detalhando os componentes refatorados, esses textos de documentação devem ser escritos em **Português**.
